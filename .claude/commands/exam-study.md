# /exam-study — 자격증 시험 D-day 일일 학습

D-day 카운트다운 방식의 자격증 시험 대비를 요약정리 + 1문제씩 대화형 퀴즈로 진행하고,
결과를 `Study/<자격증명>/D<n>-<주제>.md`에 저장 + 학습 계획을 최신 상태로 업데이트한다.

기술 스택 학습은 `/study`를 사용할 것 — 이 스킬은 **시험 일정이 있는 자격증 대비 전용**이다.

## Steps

### Phase 0: 학습 계획 확인/설정 (최초 1회, 이후 세션은 스킵)

1. 메모리에서 해당 자격증의 계획 메모리(`type: project`, 이름 패턴 `<자격증>-plan.md`)를 찾는다.
2. **없으면** 사용자와 함께 확정 후 메모리에 저장:
   - 시험명 / 시험일시 / 장소 / 접수 여부
   - 전체 대비 기간(D-n ~ D-1)과 **단계별(Phase) 커리큘럼** — 무엇을 몇 일차에 다룰지 순서 목록
   - 산출물 규칙: `Study/<자격증명>-<실기|필기>/D<n>-<주제>.md`, 문서 구성(요약정리+문제20개+해설+반복오답패턴), 학습 방식(1문제씩 대화형)
3. **있으면** 계획을 읽고 오늘이 D-몇 인지, 커리큘럼상 오늘 다룰 주제가 무엇인지 계산한다.

### Phase 1: 오늘의 학습 세션

1. 시작 안내: "D-<n> <주제> 학습 시작합니다" + **요약정리**를 먼저 제시한다.
   - 피상적 설명 금지 — 원리/비교/헷갈리는 개념 쌍/표를 적극 활용 (`/study`와 동일한 톤)
2. 문제 **20개를 한 번에 주지 말고 1개씩 순차 출제**한다. 사용자가 답하면:
   - 즉시 정오(**O**/**X**/**△** — 부분정답) 판정 + 2-3문장 해설
   - 핵심 키워드/메커니즘이 빠졌으면 O가 아니라 △ (방향만 맞고 근거 없으면 X에 가깝게 엄격히 판단)
   - 사용자가 "모르겠다"거나 개념을 되물으면 풀어서 설명 후 **같은 문제 번호로 복귀**해 다음 문제로 진행 (질문에 대한 답이 다음 문제 진행을 막지 않게)
3. 20문제 종료 후 O/X/△ 개수 요약 + 오늘 자주 틀린 패턴 3-5개를 짚는다.

### Phase 2: 문서화

`Study/<자격증명>-<실기|필기>/D<n>-<주제-슬러그>.md` 로 저장. 템플릿(정처기 D16/D15 문서와 동일):

```markdown
# [<자격증명>] D-<n> — <주제>

> 시험일: <YYYY-MM-DD>(요일) <시각>, <장소>
> 학습일: <YYYY-MM-DD>

---

## 1. 요약정리
<Phase 1에서 제시한 요약정리>

## 2. 문제 (20문제)
> 맞음(O) / 틀림(X) / 부분정답(△) 표시만 남겨둠. 해설은 맨 뒤에 모아서 정리.
1. <문제> — **<O|X|△>**
...

## 3. 해설
1. **정답: <정답>**. <왜 틀렸는지/부족했는지, 헷갈린 개념과의 구분>
...

## 4. 반복 오답 패턴 (D-2 최종 암기 시 재확인)
- <패턴>
```

**커밋/PR** — `/study` Phase 2와 동일한 방식:
```bash
git checkout main && git pull origin main
git checkout -b docs/study-d<n>-<주제-슬러그>
git add "Study/<자격증명>-.../D<n>-....md"
git commit -m "$(cat <<'EOF'
docs(study): <자격증> D-<n> <주제> 정리

Co-Authored-By: Claude <noreply@anthropic.com>
EOF
)"
git push -u origin docs/study-d<n>-<주제-슬러그>
gh pr create --title "docs(study): <자격증> D-<n> <주제> 정리" --body "..."
```
머지는 사용자 승인 후에만(CLAUDE.md 룰). 사용자가 "머지까지" 명시하면 바로:
```bash
gh pr merge --squash --delete-branch
git checkout main && git pull origin main
```

### Phase 3: 일정정리 (★ 매 세션 마지막 필수, 스킵 금지)

1. **계획 메모리 업데이트**:
   - 오늘 D-<n>을 완료 처리, 오늘 성적(O/X/△ 개수) 한 줄 기록
   - 오늘의 "반복 오답 패턴"을 계획 메모리의 누적 취약 항목 목록에 append (D-2 최종 암기 때 전체 취합해서 재사용할 수 있게)
2. 커리큘럼 기준으로 **다음 회차(D-(n-1)) 주제**를 계산해 안내: "다음은 D-<n-1> <주제>입니다"
3. 전체 계획 대비 진행 상황(몇 Phase 중 몇 번째, 남은 일수)을 한 줄로 언급
4. D-3 이하로 임박했는데 캘린더(시각/장소 등)에 빠진 정보가 있으면 상기시킨다. 캘린더 자체를 뒤지러 가지 말고, 계획 메모리에 기록된 내용 기준으로만 언급

## Rules

- 문제는 **절대 한 번에 20개를 다 던지지 않는다** — 반드시 1개씩, 대화형으로
- 정오 판정은 핵심 키워드/메커니즘 포함 여부로 엄격하게 (방향만 맞으면 △, 아예 다르면 X)
- 문서 템플릿·저장 경로 규칙은 이미 확립되어 있으므로 **매번 사용자에게 재확인하지 않는다** (새 자격증을 처음 시작할 때만 Phase 0에서 확인)
- **Phase 3(일정정리)은 모든 세션에서 필수** — 문서화만 하고 끝내지 않는다
- 계획 메모리가 없으면 Phase 0부터 자동 시작
- 시험 스펙/출제 경향 등 사실관계가 불확실하면 추측하지 말고 사용자에게 확인
- 커밋 전 문서 내용은 이미 대화로 확정된 것을 그대로 옮기는 것이므로 별도 초안 승인 절차 불필요 (단, PR 생성/머지는 CLAUDE.md 룰 그대로 사용자 승인 필요)
