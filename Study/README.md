# Study Index

> 프로젝트에서 사용 중인 기술스택을 대화형으로 학습·정리하는 공간.
> `/study` 커맨드로 Q&A 후 카테고리에 맞춰 문서 추가.

---

## 폴더 구조

```
Study/
├── 자격증/    ← 시험 대비 자료 (예: 정보처리기사-실기)
├── 강의/      ← 강의 회차별 정리 (예: 온톨로지-지식그래프)
├── 책/        ← 책 장별 정리
├── 아티클/    ← 엔지니어링 블로그 정리
└── 기타/      ← 기술 스택 학습 (17개 분류, 상세는 기타/README.md)
    ├── 언어/, 프론트엔드/, 모바일/, 상태관리/, UI-스타일링/, 폼-유효성검사/,
    └── 백엔드/, ORM-ODM/, 인증/, DB/, 테스트/, 인프라/, 모니터링/, 아키텍처/ ...
```

## 문서 작성 규칙

- 기술 스택 학습: `Study/기타/<카테고리>/<주제>.md` (카테고리는 [기타/README.md](기타/README.md)의 17개 분류를 따름, 예: `언어/`, `프론트엔드/`, `모바일/`, `아키텍처/`)
- 자격증 시험 대비: `Study/자격증/<자격증명>-<실기|필기>/D<n>-<주제>.md`
- 강의: `Study/강의/<강의명>/S<nn>-<주제>.md` (회차 단위, 목차·진행은 해당 폴더 README)
- 파일명: `<주제>.md` (날짜 미포함, 변경 이력은 git이 관리)
- 학습 완료 시 [기타/README.md](기타/README.md) 표의 `문서` 칸에 링크, `상태` 칸을 ✅로 업데이트
