## 1. 요약정리

### C언어
- 포인터 산술: `arr+2`는 인덱스 이동(주소 계산), `*(포인터)`는 역참조. 단항 `*`가 이항 `+`보다 우선순위 높음(`*arr+1` = `(*arr)+1`)
- Call by Value: 매개변수를 바꿔도 원본 불변(포인터 넘겨야 원본 변경 가능)
- `static` 지역변수: 함수 종료 후에도 값 유지(일반 지역변수와 다름)
- `#define` 매크로는 텍스트 치환(함수 아님) — 괄호 없으면 연산자 우선순위 함정
- `bool` 기본타입 없음, 참/거짓도 정수 1/0
- `if(a=5)`처럼 `=`(대입)과 `==`(비교) 혼동 주의 — 대입 결과가 조건이 됨
- `sizeof(배열)/sizeof(타입)` = 배열 원소 개수 관용구
- 전위/후위 증가연산자(`++a` vs `a++`) 대입 순서 차이

### JAVA
- 오버로딩(매개변수로 컴파일시 결정) vs 오버라이딩(런타임에 실제 객체 타입으로 결정, 다형성)
- `final` 재할당 = 컴파일 에러 / String은 불변(concat 등은 새 객체 반환, 원본 불변)
- 생성자 호출 순서: 자식 생성자 실행 전 부모 생성자(super())가 명시 없어도 자동 호출
- Integer 캐싱(-128~127)은 `==` 참조비교에서 true, 범위 밖은 false
- for-each는 값 복사(원본 배열 안 바뀜) / 예외는 정확한 클래스명(NullPointerException 등)으로 답할 것
- 정수 나눗셈 vs 형변환 후 실수 나눗셈 구분, 출력문 개수 세어볼 것

### Python
- 슬라이싱 `[start:end]`는 end 미포함, `[::-1]`은 전체 역순
- 리스트 대입(`b=a`)은 참조 공유(같은 객체), `.copy()`/`[:]`는 진짜 복사
- 튜플은 불변(인덱스 대입 시 TypeError) / 정수도 불변(재대입해도 공유 변수엔 영향 없음)
- 리스트 컴프리헨션에서 0도 짝수 조건 만족(빠뜨리기 쉬움)
- **가변 기본값(`def f(lst=[])`)은 함수 정의 시 한 번만 생성되어 호출마다 재사용됨** — 최다 함정
- `int == float`는 값 기준 비교(타입 달라도 True 가능)

### 알고리즘/순서도
- 버블정렬 1회전 트레이싱 시 마지막 비교까지 놓치지 말 것 / 선택정렬은 비교 O(n²)지만 스왑은 최대 n-1번
- 이진탐색은 정렬된 배열 전제, O(log n) / 순차탐색 O(n), 정렬 불필요
- **BFS=최단경로 보장+큐 / DFS=재귀·스택+최단경로 보장 안 됨** — 반대로 암기하기 쉬움
- 재귀 종료조건(Base Case) 없으면 "무한루프"가 아니라 **스택 오버플로우**
- 정렬 회전수는 "최악의 경우 상한(n-1)"과 "실제 데이터 트레이싱 결과"를 구분해서 답할 것
- 병합정렬 = 분할정복(반씩 나눠 재귀 후 병합) / 안정 정렬 = 동일값의 원래 순서 유지

### SQL심화 + 언어복합
- 상관 서브쿼리(외부 행 참조, 행마다 반복 실행) vs 일반 서브쿼리(1회 실행)
- WHERE(그룹화 전, 집계함수 불가) vs HAVING(그룹화 후, 집계함수 가능)
- FROM절 서브쿼리 = 파생 테이블(뷰와 비슷하지만 비저장, 별칭 필수)
- **`NOT IN`은 서브쿼리 결과에 NULL이 하나라도 있으면 전체 결과가 비어버림 — `NOT EXISTS`가 안전**(실무 함정)
- `GROUP BY 여러컬럼`은 각각 따로가 아니라 **컬럼 조합이 같은 행끼리** 그룹화
- RANK(동순위 시 다음 순위 건너뜀) vs DENSE_RANK(안 건너뜀)
- CASE WHEN(조건별 값 분류), COALESCE(NULL이면 기본값), SELF JOIN(같은 테이블 별칭 두 개로 참조)

## 3. 반복 오답 패턴 (D-2 최종 암기 시 재확인)

- **C**: 포인터 산술(`arr+2`≠값+2), Call by Value(원본 불변), `static` 지역변수(값 유지), 매크로(텍스트 치환, 괄호 함정), `bool` 없음(정수 1/0), `=`/`==` 혼동, `sizeof`로 배열 길이 구하기
- **JAVA**: `final` 재할당=컴파일 에러, String 불변(원본 안 바뀜), 생성자 호출 순서(부모 먼저 자동), 예외는 정확한 클래스명
- **Python**: 슬라이싱 end 미포함, 리스트 참조공유 vs 복사, 튜플 불변, **가변 기본값 함정(최다 출제)**, 정수 불변
- **알고리즘**: BFS/DFS 반대 암기 주의, 재귀 종료조건 없으면 스택오버플로우(무한루프 아님), 최악상한 vs 실제 트레이싱 구분
- **SQL심화**: `NOT IN` + NULL = 결과 없음 함정(`NOT EXISTS` 사용), `GROUP BY 여러컬럼`은 조합 기준
