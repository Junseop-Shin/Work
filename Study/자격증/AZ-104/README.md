# AZ-104 Microsoft Azure Administrator 재응시

> 시험일: 2026-10-19(월) 오전, Pearson VUE
> 응시료: 99달러

---

## 1. 출발점

2025-12-31에 632점으로 떨어졌다. 합격선은 700점이다. 열 달이 지났으니 내용은 다 잊었다고 보고 처음부터 다시 한다. 실무에서 만져본 경험만 남아 있다.

지난 점수표의 영역별 결과다. 정답률은 막대 길이를 눈으로 읽은 값이라 순서를 보는 용도로만 쓴다.

| 영역 | 비중 | 지난 정답률(추정) |
|---|---|---|
| ID·거버넌스 관리 | 20~25% | 약 58% |
| 스토리지 구현·관리 | 15~20% | 약 44% |
| 컴퓨팅 리소스 배포·관리 | 20~25% | 약 55% |
| 가상 네트워킹 구현·관리 | 15~20% | 약 78% |
| 리소스 모니터링·유지 관리 | 10~15% | 약 47% |

점수표가 꼽은 약점 셋은 스토리지 계정 구성, ARM 템플릿·Bicep 배포 자동화, 백업·복구다.

## 2. 공부 방식

문제를 풀다가 막히는 개념을 질문하고, 답을 시험 영역별 문서에 기능 단위로 모은다. 문항 번호나 문제 원문은 적지 않는다. 문제와 별개로 실무에서 궁금했던 질문은 실무 폴더에 따로 둔다.

| 날짜 | 한 일 |
|---|---|
| 10/17 | ExamTopics 1~30번(무료 범위). 유료 범위는 보지 않기로 했다 |
| 10/17~10/18 | MS Learn 공식 연습 평가 2회차를 같이 풀며 질문 정리 |
| 10/19 | 시험 |

[MS Learn 공식 연습 평가](https://learn.microsoft.com/ko-kr/credentials/certifications/azure-administrator/practice/assessment?assessment-type=practice&assessmentId=21&practice-assessment-type=certification)는 한 회 50문항이고 시간 제한이 없다. 문항마다 해설과 Learn 문서 링크가 붙어 있다.
